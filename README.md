E-Commerce SQL Data Analysis Project

Project Overview

This project demonstrates end-to-end SQL data analysis on a simulated e-commerce dataset to uncover customer behavior, sales trends, and revenue growth patterns.
It includes basic, intermediate, and advanced SQL queries that reflect real-world analytical scenarios, making it a strong demonstration of business intelligence and SQL proficiency.

Objectives

Strengthen SQL querying, aggregation, and analytical logic.

Practice data extraction, transformation, and insight generation using SQL.

Apply window functions, subqueries, and joins for complex analysis.

Understand customer retention, sales performance, and revenue growth patterns.

Dataset Description

The dataset simulates a large-scale e-commerce business containing:

Table	Description
customers	Customer details (ID, name, city, state).
orders	Transaction data with order date and payment method.
order_items	Products per order with quantity and price.
products	Product details such as category and price.
sellers	Seller details including seller ID and region.
payments	Payment info (installments, value, method).
